LED Menu Control

Operator guide — for the person running the menu board at an event

If anything ever looks wrong on the LED wall: press Ctrl+Shift+F12 to stop output, or Ctrl+Shift+B for a blackout (pure black, one press to bring it back). Neither deletes or changes anything. These work even when another program is in front, as long as output is running.

1. What this program does

It shows your menus on the LED wall. The PC sends a picture to the wall's controller (the Mirackle VP2) over HDMI, exactly like a second monitor. You choose what is on the wall in this program's window on your normal screen; changes appear on the wall straight away. There is no “publish” step.

Three words to know:

  • Display – a monitor or the LED controller, as Windows sees it. One of them is the LED output.
  • Screen – a rectangle inside the LED picture, usually one section of the wall. A common one is 336×672 (the left two panels) or 168×672 (one panel column). You can have several screens, each with its own menu.
  • Menu – the content: a header, optional logo, categories and items with prices. A menu is shown by assigning it to a screen.

2. First-time setup (once per wall)

Do this at your desk before the event. The settings are remembered.

  1. Connect and set up Windows. Plug the PC's HDMI into the VP2. In Windows Settings → System → Display, choose Extend these displays, set the LED display to 1920 × 1080 and keep your normal monitor as the main display. With the VP2's scaling switched off, the wall shows the top-left corner of that picture at 1:1, one picture pixel per LED.
  2. Choose the LED display. Open the Displays tab. Click Identify Displays to see a number on each monitor, then click Use as LED Output on the card for the LED display. (Use as Operator Display marks the screen you work on; this helps the program warn you if output would cover it.) The program remembers each display by its device ID, so Windows renumbering displays does not confuse it.
  3. Make the screens. Open the Screens tab. Click Add Screen (336×672) or Add Screen (168×672). The numbers X, Y, Width and Height are the real settings; dragging in the picture only fills them in. Put the screen where the matching panels are (the wall's first panel is at X=0, Y=0). Screens that are wrong are flagged and left exactly as you typed them. Enabled switches a screen on or off without losing its settings.
  4. Check the alignment. Press Start Output, choose Screen Calibration under Output shows, and look at the wall: every screen gets a border, corner markers and a centre cross. If an edge or corner is missing, the screen is not where you think it is. Output Canvas Calibration shows the whole 1920×1080 picture with rulers, which tells you how much of it the wall actually shows. Choose Normal Output when done.
  5. Create or choose a menu. Open the Menu Library tab. New Menu makes an empty one (or add a sample to try things out). Set its name, header, subtitle, logo (Set Logo…), seconds per page and whether to show page numbers.
  6. Put the menu on a screen. Back on the Screens tab, pick the menu in the screen's menu box.
  7. Fill in the menu. See section 3.

3. Everyday use: the Menu tab

This is the tab that opens when you start the program. Pick the menu at the top. Each item is one row:

ControlWhat it does
Price boxType a new price. It is free text: $12, $12 / $16, 3 for $10, Market Price.
Sold Out / Back in StockMarks the item sold out (red badge, dimmed, struck through) without moving anything. Press again to undo.
Hide / ShowRemoves an item from the wall entirely (the rest moves up); Show brings it back in the same place.
EditName, description, Featured, category, move up/down, delete.
Add Item / Add CategoryNew entries. A category can be hidden (Hide Category) with all its items.

Everything saves by itself: buttons save at once, typing saves half a second after you stop. Closing the program saves anything still waiting. If a save fails (disk full, file locked) a red notice says so, the change stays on screen, and the program keeps retrying.

If a menu is longer than the screen, it is split into pages that rotate on the wall (the Menu Library sets how many seconds each page stays). Items are never cut in half and a heading is never left alone at the bottom of a page. A notice at the top of the Menu tab tells you if a single item is too big to fit.

4. Running the wall

Start and stop

Start Output opens the LED picture on the LED display and covers it completely. The badge at the top right shows OUTPUT: LIVE. Stop Output (or Ctrl+Shift+F12) closes it again; your menus and settings are not affected. The program always starts stopped and never starts in blackout. If the operator window is on the same display as the LED output, you are warned before output starts.

The preview

The panel on the right shows exactly the picture that goes to the wall (it is the same picture, not a copy). Choose Whole output or one screen, and a zoom: Fit, or 100% actual pixels up to 400%, where every LED is a clear square. The badge shows LIVE, STOPPED or BLACKOUT. You can check a menu without starting output.

Blackout

The red BLACKOUT button (or Ctrl+Shift+B) turns the whole wall pure black. While it is on: a red banner appears, the badge says OUTPUT: BLACKOUT, the button reads END BLACKOUT, and the preview is black. Your menus keep updating behind it, so ending blackout shows what is current. Stopping output always clears blackout.

The three Ctrl+Shift shortcuts work from any program while output is running. None of them can delete anything.

6. When something goes wrong

What you seeWhat it means and what to do
Badge says NO DISPLAY or CONFIRM DISPLAYThe LED display is not connected, or Windows changed its ID. Reconnect it, or on the Displays tab confirm it. The program never uses a different display on its own.
Output stopped by itself and a message says the display is no longer availableThe LED display was unplugged or switched off. Output stops rather than jumping to another monitor. When the same display comes back, output restarts by itself and says so. If you pressed Stop yourself it will not restart on its own.
A screen on the wall is blackIt is disabled, has no menu, its menu was deleted, it hangs outside the picture, or its menu failed to draw (a warning names it). Other screens are not affected.
Amber notice about a logo or fontThe logo file is missing or unreadable, or a font fell back to a system font. The menu is still shown without the logo. Re-select the logo in the Menu Library.
Red notice: “The menu could not be saved”Disk full or file locked. Your change is still on screen and the program retries every few seconds and when you close it. Free up space or close whatever has the file open.
Banner at start saying data was recoveredA data file was damaged (for example by a power cut). The latest good backup was restored automatically; the damaged file was kept beside it. Check your menus.
A “Something went wrong” dialogThe program caught an unexpected error and is still running. Details are in the log. The same error will not pop up again for two minutes.

7. Your files, backups and moving to another PC

  • Everything you create lives in %APPDATA%\LedMenu (paste that into the Explorer address bar): menus (one file per menu), settings.json, screens.json, assets (logos), backups, trash (deleted menus, recoverable) and logs.
  • To back up or move to another PC: close the program and copy the whole LedMenu folder. On the new PC put it in the same place, or set the Windows environment variable LEDMENU_DATA_DIR to the folder you want to use.
  • To update the program: replace the program folder with the new one. Your menus are not in it.
  • The program keeps the ten most recent backups of each data file, writes files safely (never half-written), and never deletes a damaged file.
  • The log (logs folder, one file per day, kept 14 days) is what to send when asking for help.

8. About the wall (technical notes)

  • Tested with a Mirackle VP2: with a 1920×1080 Windows signal and scaling off, the wall shows the upper-left of the picture at 1:1. Each panel is 168×336 pixels. A 336×672 screen at X=0, Y=0 fills the leftmost 2×2 panels exactly; a 168×672 screen at X=0 fills the leftmost 1×2 column.
  • Each menu is drawn at the screen's own pixel size, never stretched from a bigger picture, so text stays crisp. The built-in layout is designed for 336×672 and also fits 168×672.
  • The font is Lato (bundled, SIL Open Font License).
