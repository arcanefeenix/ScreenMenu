  The files are copies of the "LatoWeb" files that ship with Windows on the development PC.
  Lato is the default font because it is open-licensed, so it can travel with the app, and it is
  very legible at small pixel sizes.

Using a different font (for example a brand font)
  1. Copy the .ttf / .otf files for the font into this Fonts folder (next to the program).
  2. Put the font's family name in the menu's theme (FontFamily).
  3. If the family cannot be found, the app falls back to Lato and shows a warning.
  Make sure the font's license allows you to use and copy it this way.
